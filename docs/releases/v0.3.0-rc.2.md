# v0.3.0-rc.2 — bounded opaque GitHub credentials

This release candidate fixes a controlled-pilot compatibility failure before provider dispatch. GitHub installation tokens are opaque and can exceed the prior 256-byte limit. The daemon private-file reader and native provider transport now share a bounded 4096-byte limit. Empty, oversized, non-graphic ASCII, prefixed and header-injection inputs remain rejected. Credential inputs are wiped on both accepted and rejected construction paths.

A regression test covers accepted lengths through the upper bound and rejected empty, oversized, CRLF, non-ASCII and prefixed inputs. Existing lifecycle, locked-memory, policy, durable-claim and transport requirements remain in force.

The v0.3.0-rc.1 tag and artifacts remain unchanged. RC.2 is a release candidate, not a production certificate. Publication and pilot success require this candidate's platform CI, provenance and clean-install verification. The earlier live pilot stopped before dispatch; no issue was created.
